Guia de Sintaxe `samba-tool`

Copie e execute os comandos gerados no seu terminal Samba AD DC.

samba-tool CLI Log 
# Registros de comandos samba-tool gerados nesta sessão:
sudo samba-tool user list
sudo samba-tool group list
sudo samba-tool computer list
sudo samba-tool ou list
sudo samba-tool gpo listall
